Just A Really Very Intelligent System

## Что уже сделано

- Настроено взаимодействие с Yandex AI Studio через OpenAI‑совместимый клиент (модель deepseek-v4-flash/latest)
- Реализован базовый агент J.A.R.V.I.S.:
  - файл: `brain/jarvis_agent.py`
  - функция: `ask_jarvis()`
- Подключён веб‑поиск
- Интеграция с Flask:
  - endpoint `POST /api/chat` принимает JSON `{"text": "..."}`
  - вызывает `ask_jarvis(...)` и получает текстовый ответ
  - текст передаётся в Silero TTS (модель для озвучки)
  - результат возвращается как WAV‑файл (`audio/wav`)

## Модуль камеры

Добавлен `camera.py` — отдельный Flask-сервер для камеры Raspberry Pi на Picamera2.

Реализованы:
- Зеркальные фото JPG и запись видео MP4 без звука.
- Получение и удаление контента по названию и типу.
- Текстовый список контента с датами сохранения.
- Хранение файлов в `media/photos/` и `media/videos/`, сведений — в SQLite.
- Автоматические названия `photo1`, `photo2`… и `video1`, `video2`… Названия необязательны, дубликаты внутри одного типа запрещены.

### Эндпоинты

| Метод | Эндпоинт | Вход / действие |
|---|---|---|
| POST | `/capture_photo/` | Необязательный `name`. Сделать фото |
| POST | `/start_video/` | Начать запись |
| GET | `/video_status/` | Получить статус записи |
| POST | `/stop_video/` | Необязательный `name`. Остановить и сохранить видео |
| POST | `/get_media/` | Обязательные `name` и `type`. Получить файл |
| DELETE | `/delete_media/` | Обязательный `type`: с `name` удаляет указанный файл, без имени — последний выбранного типа |
| GET | `/list_media/` | Получить текстовый список названий, типов и дат |

Параметры передаются в Body как JSON. `type` — `photo` или `video`. Если контент не найден — `404`, название занято — `409`.

При конфликте названия видео запись останавливается. Повторите `/stop_video/` с другим именем или без имени до перезапуска сервера.

### Запуск на Raspberry Pi

Установка: `sudo apt install python3-flask python3-picamera2 ffmpeg`

Запуск: `python3 camera.py`

Адрес сервера: `http://IP_RASPBERRY:5000`.
